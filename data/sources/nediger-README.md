# Nediger-list

This wordlist includes spaces, apostrophes (and apostrophe-like marks), and hyphens (and hyphen-like marks). There are four scores: 25 (entries I'll use only if absolutely necessary), 49 (entries that are likely too racy for many mainstream venues), 51 (entries I'll use in most circumstances), and 99 (for up to 7 letters, entries that are very easy and/or inferable, and for 8 or more letters, entries that would be considered assets in many venues). The 51 vs 99 scoring for long entries is very sporadic and unsystematic.

I created the wordlist by hand, with much help from Wikipedia, OneLook, and other freely available wordlists. I've caught and fixed many typos, but because I typed out everything personally, there are likely some remaining typos. If you find one, please let me know and I'll fix it right away!

The list is free to use, but it took countless hours of labor to create, so if you find it useful, I wouldn't say no to a donation at my website (http://blog.bewilderinglypuzzles.com/).
